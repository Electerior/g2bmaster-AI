## 2차: 나라장터 직접 더블체크 (필수)

- https://www.g2b.go.kr 메인의 입찰공고 검색 위젯 (로그인 불필요). 공지 팝업 먼저 닫기
- 나라장터 키워드 검색은 **공고명만 매칭** (품명 검색 아님)
- **키워드 스윕 세트**: 컴퓨터, 서버, 데스크톱, 데스크탑, 워크스테이션, GPU, DGX, PC, 노트북
- 공고번호 검색 = 기간 제한 없음 → 분석 공고의 상태(등록/변경/취소) 재확인 용도
- **누리장터(민간)**: 같은 검색화면에서 조달유형=민간 라디오로 조회 (별도 사이트 방문 불필요)
- 키워드 오탐 주의: "PC"=폴리카보네이트(3D프린터 소모품), 컴퓨터공학부 발주 계측기 등

## 공고 검증 규칙

- **나라장터의 개찰일시가 공식 기준**. 첨부 공고문 날짜와 다르면 나라장터를 믿고 발주처 확인 메모
  (실사례: 가천대 R26BK01685019에 타 공고 공고문이 첨부되어 있었음 - 개찰일 7일 차이)
- 문서번호(예: 산학202610058)로 취소↔재공고 관계 추적
- 같은 기관의 동일 규격 분할 공고: 규격서 diff로 동일 확인 후 가격조사 1회로 커버
- 일부 공고는 나라장터 밖 시스템 진행: ebiz4u(가천대), 대학 자체 전자구매+서면접수(아주대)
  → 접수 방식·서류 마감·투찰 일시를 공고문 본문에서 별도 확인
- **재공고는 유찰 사유를 추정하지 말고 조회한다.** 상세의 `연관정보 > 관련공고`에 1차 공고번호가
  링크돼 있고, 그 번호로 **개찰결과분류조회 → 진행상태 `유찰` 버튼**을 누르면 상세에
  `유찰사유` 필드가 그대로 나온다(비로그인 가능).
  실사례 2026-08-20 부산대 딥러닝서버 R26BK01688589: 1차 R26BK01659789의 유찰사유가
  **"단독응찰"** — 예산 부족이 아니라 응찰자가 1곳뿐이라 유효입찰(2인 이상)이 안 된 것이었다.
  이 값이 경쟁 강도·투찰 전략을 바꾼다(단독응찰 유찰이면 실질 경쟁자는 1곳이고,
  그쪽은 규격을 사전 파악한 업체일 개연성이 높다).

## 직찰(현장입찰) 공고 판별 — 나라장터는 게시판일 뿐이다

나라장터 상세의 **입찰방식이 "직찰"**이면 접수·투찰·개찰이 전부 발주기관 현장에서 진행된다.
나라장터에는 공고만 미러링되고 **개찰결과가 남지 않는다** (구버전 공고번호는 `유찰`+사유
"직찰로 진행함"만, R-번호 신버전은 개찰결과분류조회에서 `데이터가 없음`).
실사례: 대구대학교 기계기구 단가구매 2023~2025 3개년 전부 낙찰자 미공개.

직찰 공고에서 확인할 것:
- 현장설명회 **참가 필수** 여부 (미참가 시 입찰 자체 불가 → 일정 확보가 최우선)
- 현장 등록 시각(보통 개찰 20분 전 창구 마감) + 지참 서류(법인인감증명·등기부 3개월 이내 원본)
- 입찰·계약보증금이 **위약벌**인지(= 몰취해도 손해배상 별도 청구). 국가계약법이 아니라
  기관 자체 재무·회계규정이 적용되면 이의신청 창구도 없다.
- "본교를 상대로 소송한 이력이 있으면 참가 불가" 류 조항 → 분쟁 시 영구 배제 = 락인

## 기존 납품업체(인컴번트) 확인법

대형 단가계약의 낙찰자가 비공개여도, **같은 기관의 소액견적 낙찰 이력으로 품목별 점유율을
집계**하면 사실상의 고정 거래처가 드러난다. 대학은 대개 자체 전자입찰 시스템에 낙찰공고
게시판을 운영한다(예: 대구대 `bid.daegu.ac.kr` → 낙찰공고 → 소액견적, 비로그인 열람 가능.
학년도 + 견적건명 키워드로 조회, 낙찰자 컬럼 존재).

- 품목 키워드(컴퓨터/모니터/복합기)별로 **연도별 낙찰자 점유율**을 세면 된다.
  실사례(대구대): 복합기 = 삼성프라자 88~91%(2024~2026), 컴퓨터 = 디지탈맥스 64%(2024)·36%(2025)
- Nexacro 그리드는 가상 스크롤이라 DOM에 보이는 25~28행만 잡힌다. **그리드 위에서 휠 스크롤
  하며 누적 수집**해야 실제 건수가 나온다(집계 전 반드시 확인 — 91건이 26건으로 잘렸던 사례).
- 점유율이 높다고 자동 배제할 이유는 아니지만, **예상 경쟁자·가격대 추정과 규격 출처 해석**
  (그 업체가 매년 납품하던 모델이 규격서에 박혀 있을 가능성)에 쓴다.

## 독소조항 체크리스트 (2026-08-20 추가 — 공고문·규격서를 받으면 반드시 이 순서로 검사)

마진율보다 먼저 볼 것. 아래 항목은 실제로 마진을 날리거나 참가 자체를 막은 사례다.

**A. 진입장벽형 (참가 가능 여부를 바꿀)**
- **특정 모델명 지정 + "시방서 명기 동일 제품로 납품"** → 동등이상 조항과 충돌하면 사실상 지정공고
  (2026-08-20 가천대 약대: 15종 전부 모델명 지정 + LABY 시리즈는 ㈜랩241 독점·온라인 유통 전무)
- **국내 정식 유통되지 않는 규격 + "국내 A/S 가능할 것"** → 병행수입으로 충족 불가
  (송원대: Kompanio Ultra 910 크롬북은 국내 미유통)
- **제조사 커스텀 요구** (예: "WiFi 기능 제거 실물기준", "기관 전용 드라이버") → 총판 경유 필수
- **특정 벤더 SW 종속 기능** (예: 터치패널 20명 동시 작업큐 우선순위 = PaperStream NX Manager)
- **공인 파트너/트레이너 자격증** 제출 (Google for Education 공인 트레이너 등)
- 업종제한 복수 동시 충족 (예: 세부품명 등록 + SW사업자 1468 동시)
- **공동수급 불가** → 부족한 역량을 컨소시엄으로 메울 수 없음. A군 항목과 겹치면 사실상 참가불가

**B. 무제한 책임형 (수주해도 적자 날 수 있음)**
- **전량 리콜 조항**: "전체 수량의 5% 이상에서 동일 유형 장애 시 전량 신품 교환, 비용 전액 업체 부담" ← 최악 생산으로 계약금 전액 손실
- **전국 SLA**: 도착 2~5h + 도착 후 2h 복구 → 자체 AS망 없으면 불가
- **하자보수 범위 확장**: 납품물 외 OS·발주처 정보시스템 SW까지 포함
- **내용연수(6년) 부품·소모품 공급 확약**
- **예비부품 5% 이상 무상 확보**
- **수량·설치장소·일정 변경 시 무상 재배치·이동설치 응대 의무**
- **"제안 단가에 따라 수량 확대 요구 가능"** → 저가 투찰 시 물량만 늘어남
- **배관배선·설치 일체 포함 + 현장설명회 없음** → 실측 불가 상태에서 시공범위 리스크 전가

**C. 절차·일정형 (몰라서 놓치면 규격 부적격)**
- **서면서류 방문제출(우편 불가)** — 마감이 전자투찰보다 앞설 수 있음
- **담당자 서명·날인을 받아야 하는 물품확인서** — 캐퍼스 방문 필요, 제출처와 다른 장소일 수 있음
  (가천대: 인천 메디컬캐퍼스에서 서명 수령 → 성남 가천관 1009호에 제출, 2회 방문)
- **규격·가격 동시입찰**: 규격 부적격이면 가격입찰서 개찰 자체를 안 함
- **입찰보증금 실물 증권 제출**(면제 아님) / 낙찰 7일내 미체결 시 낙찰무효+보증금 귀속
- **납품기한 30일 이내 + 분할납품 불가** → 수입·라이선스 발급·교육까지 30일 내 완료 가능한지
- **대금지급이 리스계약 경유** → 회수 시점 지연(국세청: 4분기 리스료)
- 낙찰 후 **적합성 검증용 테스트 장비 사전 납품**, 미적합 시 계약 취소
- **청렴계약 위반 손해배상 입찰가 5% / 계약금 10%**

→ 분석 파일에는 이 항목들을 meta.quali·summary에 전문 기록하고, 보고 시 마진율보다 먼저 제시한다.

## 소액수의견적(2인 이상)의 낙찰하한율 — 88%가 아니라 90%, 기준도 기초금액이 아니다

2026-08-20 극지연 R26BK01689520에서 실제로 틀렸던 부분. 적격심사(87.995%)나 제한적최저가(88%)
습관으로 0.88을 넣으면 **투찰이 무효**가 된다.

- 나라장터 상세 `낙찰하한율` 필드를 그대로 읽을 것 (이 건은 `90.000 %`)
- 공고문 문구: "예정가격의 90% 이상으로 견적서를 제출한 자 중 최저가"
  → 기준은 **기초금액이 아니라 예정가격**. 예정가격은 기초금액 ±2%로 만든 복수예비가격
  15개 중 4개를 추첨해 산술평균한 값이다(상세의 `예가방법: 복수예가 4/15`).
- 따라서 안전 투찰율(기초금액 대비) x는 `x ≥ 0.9 × (예가/기초)`. 예가가 기초의 102%로
  뽑히면 x ≥ 0.918까지 올라간다. 0.88은 예가가 최저(98%)로 나와도 89.8%라 전 구간 무효.
- 분석 파일 이율은 0.90을 기본으로 하되, 무효 위험 회피가 필요하면 0.91~0.92 시나리오를 병기.
- `기초금액공개` 그리드가 `자료없음`이면 기초금액은 아직 미공개다. 사업금액(=추정가격+부가세)을
  대신 넣었다면 비고에 명시할 것.

## 물품내역서에 품목별 상한이 걸린 공고 — 총액 마진율이 거짓말을 한다

내역서 각주의 "각 물품별 계약금액은 VAT 포함 추정가격을 초과할 수 없습니다" + 공고문의
"각 품목별 가격은 물품내역서에 기재된 금액을 초과하지 않도록 작성"이 같이 있으면,
**총액을 하한율로 곱한 마진율은 의미가 없다.** 품목별로 `상한 × 하한율` vs 매입가를 따로 계산해야 한다.

- 부서별 개별 견적을 합산한 공동구매형 공고(인수자·납품실이 품목마다 다름)는 각 부서가
  이미 시장가를 조회해 예산을 잡아둔 것이라 **대부분 품목이 하한율 투찰 시 역마진**이다.
- 실제로 극지연 18품목 중 마진이 난 건 5품목뿐이고, 총마진 143만원 중 240만원이
  단 한 품목(GPU 요구가 없는 모바일 워크스테이션)에서 나왔다. 나머지는 전부 마이너스.
- → 보고할 때 총 마진율만 쓰지 말고 **어느 품목이 마진을 만들고 어느 품목이 까먹는지**를 표로 낼 것.

## 견적서에 품목별 모델명·가격을 첨부해야 하는 공고 = '견적 필요' 항목을 남길 수 없다

"견적서(각 품목별 가격 및 상세규격내역(규격, 모델명) 작성)를 전산 첨부복호화하여 필수 제출,
미첨부 시 낙찰자 선정 제외" 조항이 있으면 **전 품목 모델을 확정해야 입찰이 가능하다.**
분석 단계에서 미확정 품목을 추정단가의 N%로 뭉뚱그려 두면 투찰 자체를 못 한다.

## 제외 기준

- 용역/렌탈/유지보수성 공고 (워런티 패키지는 물품으로 나올 수 있음 - 파트너 견적 필요 표시)
- 취소공고, 투찰 준비 시간 없는 마감 임박 공고 (제외 시 사유 기록)

## 재공고에서 뭐가 바뀌었는지는 첨부 md5로 1초에 판정한다 (2026-08-21)

공고문·규격서를 눈으로 비교하지 말 것. 원공고/재공고 첨부를 각각 받아 `md5`를 비교한다.

```bash
# 첨부 URL 패턴은 spec-extraction 스킬 참조 (fileSeq는 첨부 목록 순서)
md5 orig_규격서.docx re_규격서.docx     # 같으면 규격 한 글자도 안 바뀐 것
diff <(추출 orig_공고문) <(추출 re_공고문)  # 보통 날짜 몇 줄만 바뀐다
```

송원대 R26BK01686155(재공고) ↔ R26BK01674679(원공고): 규격서 md5 완전 동일
(`cc55dc244782f8c779fb545074999e93`), 공고문 diff는 일정 4줄뿐, 기초금액도 108,120,000원 동일.
즉 **발주처가 유찰 원인을 규격·예산 어느 쪽으로도 조정하지 않았다** → 완화 협의 여지가 없다는
근거가 된다. 반대로 규격서가 바뀌었으면 그 diff가 곧 "발주처가 인정한 완화 지점"이다(규칙 10).


## 예산 역산으로 '이 공고가 누구 걸로 짜였는지'를 읽는다 (2026-08-21 가천대 약대 R26BK01686166)

**"우리가 랩241 딜러가를 계약단가의 몇 %에 받아오느냐"만으로 흑자/적자가 갈린다**는
것도 그 자리에서 계산된다(마진 10% 기준선: 이율 0.96이면 미확보분 ≤ 14,013,920).

→ 견적을 못 받은 상태에서도 **"얼마 이하로 받아야 하는가"는 숫자로 낼 수 있다.**
견적 요청 메일에 그 상한을 알고 들어가는 것과 모르고 들어가는 것은 다르다.
