# 독소조항·계약조건 심층 검토 (AGENTS.md 규칙 11)

## 왜 하는가

우리 마진율 계산은 **부품 원가 대비 투찰가**일 뿐이다. 계약서에는 부품비에 안 잡히는
이행비용과 위험이 들어 있고, 그게 마진을 통째로 먹거나 계약 자체를 못 하게 만든다.

**마진이 유난히 높으면 의심부터 한다.** 예산이 후한 게 아니라, 다른 업체들이 조건을 보고
안 들어오는 것일 가능성이 크다. 유찰·재공고 이력이 있으면 특히 그렇다
(예산 부족이 아니라 조건 때문에 아무도 안 들어온 것일 수 있다).

## 적용 대상 (하나라도 걸리면 필수)

- 마진율 **20% 이상**
- 계약금액 **1억 이상**
- **재공고·유찰** 이력
- 처음 거래하는 발주기관 유형(병원, 발전·에너지 공기업, 국방, 해외 납품)

## 읽을 문서

규격서만 보면 안 된다. 아래를 **전문으로** 읽는다.

- 입찰공고문(본문 + 유의사항)
- **계약특수조건 / 물품구매계약 특수조건**
- 과업지시서 / 제안요청서의 "기타조건", "책무", "제출서류"
- 물품계약일반조건(기관 자체 양식이면 반드시)
- 별표·별지(정보보안 특수조건, 안전관리 특수조건, 위약금 부과기준)
- 적격심사기준 / 평가기준표

## 독소조항 체크리스트

읽으면서 아래 항목을 표로 채운다. **해당 없음도 "없음"으로 명시**해야 확인한 게 된다.

### A. 납기·지체
- 납품기한이 부품 조달 리드타임보다 짧은가? (해외 소싱 품목 있으면 특히)
- **지체상금률** (통상 0.075%/일. 1억 계약이면 하루 7.5만원)
- 분할납품 허용 여부. 불허면 전 품목 동시 확보 필요
- 검수 지연이 지체로 잡히는 구조인가

### B. 하자·보증·SLA
- 하자보증기간 (1년이 표준. **3년이면 원가에 반영**)
- **장애 대응 SLA**: "4시간 이내 방문", "48시간 내 조치", "3일 내 현장 도착"
  → 지방 납품 + 4시간 SLA는 현지 협력사 없으면 이행 불가
- **부품 선교체 지원**, "동일 원인 3회 재발 시 신제품 무상교체"
- 하자보수보증금률 (통상 3~5%, 계약금액에서 예치)

### C. 물품·채널 제약
- **정품확약서 / 제조사 공급확약서 / 총판 증명서** 요구
  → 채널 없으면 규격 충족 자체가 불가. 병행수입 원가를 못 쓴다
- "Retail Box", "엔비디아코리아 정품", "국내 정식 유통" 명시
- **Refurbished/Used/보증서비스용 부품 금지**
- **계약일 기준 12개월 이내 단종 예정 모델 배제** → 벤더 EOL 로드맵 확인 필요
- 라이선스 증서·정품인증서 제출 (벤더 종속 신호)

### D. 이행 체계
- **하도급 불허 / 공동수급 불허** → 시공·설치를 직접 해야 함
- 직접생산확인증명 요구 (중기간 경쟁제품)
- 지역제한(본점 소재지), 실적제한, 업종·SW사업자 등록
- 기술지원확약서, 물품규격검토확인서(**마감 전 사전 제출**인 경우 일정 주의)

### E. 설치·현장
- 설치 장소 특수성: **중환자실·수술실**(감염관리·출입통제), 보안구역(신원조회),
  전산실 무중단, 야간·주말 작업 제한
- **기존 시스템 연동·데이터 이관·재구성** 포함 여부 → 엔지니어 공수가 크다
- 현장실사 없이 진행하고 "발생 문제는 전량 제안업체 책임" 조항
- 기존 장비 철거·폐기, 랙 이송, 케이블링 범위
- 교육 실시(횟수·대상 명시되면 공수 계상)

### F. 보안
- **장애 디스크 미반출 서비스** (저장매체 반출 금지) → 디스크를 회수 못 하므로
  벤더 서비스 옵션을 별도 구매해야 함. 원가 상승 요인
- 정보보안 계약특수조건, 보안각서, 투입인력 신원확인서
- **보안위규 위약금 부과기준** (금액 확인)
- 자료삭제확약서, 보안교육 이수

### G. 대금·리스크
- 선금 지급 여부, 대금 지급 시기(검수 후 N일)
- 입찰보증금 5%(보증보험 대체 가능 여부)
- 계약이행보증금률
- 부정당업자 제재 트리거 조항(서류 미제출로 계약 해제 시 제재 등)

### H. 평가·낙찰 구조
- **적격심사 가격평점 산식** — 물품적격심사는 통상
  `70 - 2 × |88 - (입찰가/예정가 × 100)|` 이라 **88%가 만점**이고 하한율은 금지선일 뿐이다.
  하한율로 투찰하면 가격점수를 크게 잃는다. 이율 설정 시 반드시 산식 확인
- 규격평가 적격 점수(85점 등), 평가위원 구성, 발표평가 유무
- 동가 시 처리(추첨/규격 우위)

## 비용 환산 규칙

정량화 가능한 항목은 **부대비용(B50)에 넣는다**. 넣은 근거를 개요에 적는다.

| 조항 | 환산 방법 |
|---|---|
| 하자보증 3년(1년 초과분) | 벤더 워런티 연장 견적, 없으면 부품가의 5~10%/년 |
| 4시간 방문 SLA | 브랜드 서버는 ProSupport/Foundation Care 옵션가. 조립은 현지 협력사 계약비 |
| 장애 디스크 미반출 | 벤더 "Keep Your Drive" 옵션가 (미확보 시 견적 필요 표시) |
| 하도급 불허 + 다지점 설치 | 지점수 × 엔지니어 1인일 × 출장비 |
| 데이터 이관·재구성 | 데이터량·기간 기반 엔지니어 공수 |
| 교육 N회 | 회당 강사 공수 |
| 각인·MSDS·시험성적서 | 건당 발급비 + 준비 공수 |

## 기록 방법

- 분석 파일 개요(A19)에 `[독소조항]` 절을 만들고 **발견 항목을 전부** 적는다.
  없으면 "특이 독소조항 없음(공고문·특수조건 전문 확인)"이라고 적는다.
- 보고에는 고마진 건마다 **"왜 마진이 높은가"에 대한 답**을 한 줄 넣는다.
  (예산이 후해서 / 채널 장벽이 높아서 / 조건이 까다로워 경쟁이 적어서)
- 이행 불가 조항을 발견하면 마진율과 무관하게 **판정을 '참가 부적합'으로 내린다**.

## 사례 (2026-08-20 축적)

- **한전기술 두코바니 서버(G092600035, 마진 53.7%)**: 하자보증 **3년** + 4시간 방문
  36개월 + **장애 디스크 미반출** + 하도급 불허 + 정보보안 특수조건(별지 10종) +
  중소 SW사업자 한정. 부품 원가만 보면 마진이 커 보이지만 **3년 SLA와 미반출 서비스가
  브랜드 옵션가로 수천만원대**라 CTO 견적 없이는 마진이 허수다.
- **삼성서울병원 e-ICU(마진 36.6%)**: 하도급·공동수급 불허인데 **중환자실 3곳 포함 4개
  병원 개별 설치**. 감염관리·출입통제로 작업시간이 제한되고, "12개월 내 단종 예정 모델
  배제" 조항이 있어 벤더 EOL 확인이 필요하다.
- **적격심사 88% 규칙**: 한전기술 건에서 확인. 하한율(80.495%)로 투찰하면 가격평점
  70점 만점에서 15점을 잃는다(|88-80.495|×2). 하한율=최적투찰가가 아니다.

- **부산대 딥러닝서버 재공고(R26BK01688589, 마진 5.2%)**: 마진이 높지 않아도 **재공고·유찰
  이력**만으로 검토 대상이다(규칙 11). 1차 유찰사유가 `단독응찰`이라 "왜 아무도 안 들어왔나"의
  답이 계약조건에 있었다 — ① 참가자격 4중 조건(컴퓨터서버 **제조** 등록 + SW사업자 1468 +
  **직접생산확인증명서** + 중소기업·소상공인 확인서) ② **공동수급·공동도급 불허**로 부족한 자격을
  컨소시엄으로 못 메움 ③ 정량평가가 **회사 규모를 직접 점수화**(기술인력 3명 미만 6.0점 /
  12명 이상 10.0점, 4대보험 가입자명부 증빙 + 신용평가등급 A- 이상 10점 / 미제출 6.0점)인데
  **85점 이상**이라야 가격개찰에 들어간다. 소규모 업체는 정량 12점이라 규격평가 80점 중 73점
  (평균 9.1/10)이 필요해 사실상 탈락.
  → **규격·가격 동시입찰에서 정량평가 배점표는 참가자격의 연장**이다. 마진율보다 먼저 봐야 한다.
- **"제조사 장비 공급서류 제안서 첨부"는 병행수입 원가를 봉쇄한다.** 정품확약서라는 단어가
  없어도 같은 효과다. 같은 건에서 GPU 병행(675.9만)과 정품(720.5만)의 차이가 장당 44.6만이었다.
- **"꼭 필요한 부분의 누락 또는 생략이 되었을 경우 무상으로 보완" 조항**이 있으면 규격서에
  안 적힌 조립 필수품(CPU 쿨러·전원 케이블·팬)이 전부 우리 부담이다. 규격서 목록만 보고
  BOM을 짜면 그만큼 원가가 샌다. 같은 건에서 sTR5 쿨러 8.4만이 통째로 빠져 있었다.
- **제안서 = 계약서와 동일한 효력** 조항(대학 산단 제안요청서에 흔함). 규격평가 점수를 따려고
  SLA·교육·유지보수를 후하게 써내면 그대로 이행의무가 되어 원가로 돌아온다.
